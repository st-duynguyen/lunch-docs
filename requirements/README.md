# requirements/

Phần **BA** giữ: những gì khách muốn, chưa phải cam kết.

| Loại | Ví dụ |
|---|---|
| Lời khách, biên bản họp | `2026-11-03-kickoff.md` |
| Spec màn hình | `screens/screen-NN-<slug>/screen.md`: màn có gì, bấm gì ra gì (danh sách: `screens/README.md`) |
| Prototype | file `.html` / ảnh do khách hoặc BA gửi |

Cam kết nằm ở `scope.md`; mỗi thay đổi ghi vì sao ở `changes/<ID>/requirement.md` và trỏ về đây, không chép lại.
